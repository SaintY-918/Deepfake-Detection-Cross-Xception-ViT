## 環境安裝 (Installation)

本專案使用 Python 3.12+ 與虛擬環境。主要依賴套件如下：

| 套件名稱 | 版本 | 說明 |
| :--- | :--- | :--- |
| PyTorch | 2.2.2 | 深度學習核心框架 |
| Timm | 0.6.5 | 預訓練模型庫 (Xception/EfficientNet) |
| Albumentations | 1.3.0 | 影像增強工具 |
| Einops | 0.8.1 | 張量維度變換處理 |
| Facenet-pytorch| 2.6.0 | MTCNN 臉部偵測器 |
| Decord | 0.6.0 | 高速影片解碼 |
